## My Projects

### 1. Cargo Bot — Personal ROS 2 Robotics R&D Project

An independent, publicly available robotics project focused on the design and simulation of an autonomous warehouse cargo robot. The project provides a complete ROS 2 workspace covering robot modeling, control, SLAM, localization, autonomous navigation, dynamic obstacle handling, simulated sensors and automated verification.

**Key capabilities and implementation:**

- Designed a modular ROS 2 Jazzy workspace containing seven packages for the robot model, custom interfaces, simulation worlds, navigation, learning examples and a native costmap plugin.
- Created a mobile warehouse robot model with a differential-drive base, cargo deck, lift, rotating and telescoping manipulator, gripper and sensor links using URDF/Xacro.
- Implemented Python ROS 2 nodes for kinematic simulation, differential-drive motion, odometry, joint-state publication, manipulator control and demonstration sequences.
- Defined custom ROS 2 messages, services and actions with validation, feedback, cancellation, operation tracking and concurrent manipulator commands.
- Built collision-enabled warehouse and multi-room Gazebo Harmonic environments using SDF and a deterministic Python world generator.
- Integrated lidar, wheel odometry and IMU data with multiple sensor profiles for ideal, realistic and harsh simulation conditions.
- Implemented mapping with SLAM Toolbox and saved-map localization using Adaptive Monte Carlo Localization (AMCL).
- Configured autonomous navigation with Nav2, Smac 2D planning, Regulated Pure Pursuit control, behavior trees and velocity smoothing.
- Implemented live obstacle detection, replanning, persistent dynamic-obstacle memory and collision-monitor safety zones.
- Developed a custom C++ Nav2 costmap layer for persistent dynamic obstacles.
- Created RViz and Gazebo launch systems, reusable configurations and automatic presentation demonstrations.
- Added deterministic unit tests, package-quality checks, ROS 2 launch tests and end-to-end acceptance tests for simulation, mapping, localization, path following and obstacle avoidance.

**Technologies used:** Python, C++, ROS 2 Jazzy, rclpy, rclcpp, Nav2, SLAM Toolbox, AMCL, Gazebo Harmonic, RViz, ros_gz (ROS–Gazebo integration), URDF/Xacro, SDF, TF, lidar, IMU, robot_localization, pluginlib, colcon, ament and Pytest.
